## 1. 背景・課題

水曜日にカメラを使ったテストを行いたい一方で、現在の説明には開発用語や細かな安全確認が多く、次の点が分かりにくくなっています。

- 水曜日にどこまでできればよいか
- 誰が何を担当するか
- 何が終わればテストを始めてよいか
- どのような場合にテストを止めるか

## 2. 目的

**8月26日（水）に、Nikon D810を1台だけ使い、「起動・接続・1枚撮影・保存確認・終了」という基本の流れを安全に試せる状態にします。**

これは製品完成の確認ではありません。まず1台で基本動作ができるかを確かめるための内部テストです。

## 4. 改善後の進め方

1. 修正済みの#130・#131が最新版に入っていることを確認します。
2. アプリ終了時の問題（#94）を確認し、水曜候補版へ入れるか決めます。
3. 自動テストは省略し、候補版で撮影しない手動確認を行います。
4. 使用する版、実行ファイル、未確認事項を記録して候補版を確定します。
5. 水曜日はD810を1台だけ接続し、操作者の合図後に最大1枚を撮影します。
6. 成功・失敗のどちらでも結果を記録し、次の判断材料にします。

### 水曜日に「できた」とする条件

- アプリが起動する
- 使用したアプリの版と実行ファイルを記録する
- 接続したD810 1台を正しく認識する
- カメラ映像の表示と停止ができる
- 操作者の合図後に、写真を最大1枚だけ撮影できる
- 撮影した写真をPCへ保存し、画面で確認できる
- アプリを正常に終了でき、関連する処理が残らない
- 実施結果を記録できる

### その場で中止する条件

- #94の確認、候補版の手動確認、使用版の記録が終わっていない
- 接続したカメラが0台、または2台以上になっている
- 専用カードや保存先に以前のデータが残っている
- アプリが止まる、終了できない、または意図せず再撮影する
- 写真が保存できない、複数できる、またはどの写真か判断できない
- 機材操作者が不在、または撮影開始の合図がない

## 6. 対象範囲

### 今回行うこと
