# 製品要件

## 1. 目的

固定したNikon D750 2台でA0級の静止した平面原稿を分割撮影し、Windows PC上で1枚の大画像へ合成する。A1より大きい原稿を、カメラ1台の画角・設置制約を超えて効率よく電子化できる状態を目指す。

## 2. MVP利用条件

- 操作者は社内の電子化作業担当者。
- 被写体は平面に近い静止原稿。
- カメラ、レンズ、原稿台、照明は固定する。
- Nikon D750 2台をWindows 11 x64 PCへUSB接続する。
- 撮影中に他のテザー撮影ソフトはカメラを占有しない。
- JPEG Fineを使用する。
- ハードウェア同期装置は使用しない。

## 3. 機能要件

### カメラ制御

- `FR-CAP-001`: 接続されたD750 2台を列挙し、永続識別情報で区別できる。
- `FR-CAP-002`: リグプロファイルに左右カメラを登録し、接続順に依存せず復元できる。
- `FR-CAP-003`: 1回の操作を1つの撮影トランザクションとして、2台へUSB撮影命令を発行できる。
- `FR-CAP-004`: 左右画像を撮影トランザクションへ確実に対応付けられる。
- `FR-CAP-005`: 初期版では撮影命令を並列、画像転送を直列に実行できる。
- `FR-CAP-006`: USB切断、片側失敗、タイムアウトを検出し、原画像と診断情報を保持できる。

### キャリブレーションと合成

- `FR-STI-001`: 左右カメラごとのレンズ歪み補正値を保存できる。
- `FR-STI-002`: 固定リグの幾何変換、重複領域、シーム、クロップ領域をプロファイルとして保存できる。
- `FR-STI-003`: 保存済み変換を適用し、許容範囲内の残差だけを補正できる。
- `FR-STI-004`: 左右の露出・色差を補正し、継ぎ目を目立ちにくく合成できる。
- `FR-STI-005`: 合成品質が基準外の場合、成功扱いにせず警告と測定値を出せる。

### 保存と操作

- `FR-DATA-001`: 左右の原画像を常に保持する。
- `FR-DATA-002`: 撮影トランザクション、カメラ別時刻、結果、エラーを記録する。
- `FR-EXP-001`: 合成JPEGを指定フォルダへ保存できる。
- `FR-UI-001`: 左右カメラの接続・Ready状態、リグプロファイル、処理進捗、結果を表示できる。
- `FR-UI-002`: 撮影、再合成、保存先表示、設定を操作できる。

## 4. 非機能要件

- `NFR-PLAT-001`: Windows 11 x64で動作する。
- `NFR-PERF-001`: 撮影開始から合成JPEG確定までp95で10秒以内を暫定目標とする。
- `NFR-REL-001`: Phase 0では100回の連続撮影で未回収画像、誤ペア、回復不能停止がないことを目標とする。
- `NFR-OBS-001`: 命令開始、受理、画像検出、転送完了、合成完了の時刻とエラーを記録する。
- `NFR-SEC-001`: 原画像と履歴をローカル保存し、MVPではクラウド送信しない。
- `NFR-MEM-001`: 推奨32GB、最低16GBのPCでピークメモリを計測し、上限を実機PoCで確定する。

## 5. 制約

- `CON-001`: Nikon D750 2台を使用する。
- `CON-002`: ハードウェアシャッター同期を追加しない。
- `CON-003`: 実シャッター開口時刻差の上限は保証しない。
- `CON-004`: 動体、手持ち、近距離立体物、リアルタイム動画は対象外。
- `CON-005`: Nikon Camera Remote SDKを二台同時制御経路に使用しない。
- `CON-006`: Nikon SDKやライセンス対象バイナリをリポジトリへ含めない。

## 6. MVP対象外

- NEF/RAW現像
- 16-bit TIFF/BigTIFF出力
- Live Viewの二台同時表示
- GPU必須処理
- 遠景・球面・円筒パノラマ
- 三台以上のカメラ
- 自動露出、オートISO、AFを使った撮影
- カメラファームウェア変更

## 7. MVP受入条件

MVPの受入は、以下をすべて満たした時点で人間が判定する。

1. 登録済みD750 2台を左右正しく識別できる。
2. 1操作で左右画像を同一トランザクションとして取得できる。
3. 原画像を失わず、再合成できる。
4. 承認済みテスト原稿で、位置ずれ、二重像、色差、継ぎ目が合意済み基準内である。
5. p95処理時間が合意済み目標内である。
6. 100回連続撮影とUSB再接続試験の結果が記録されている。
7. 未解決の安全・ライセンス・リリースゲートがない。

数値品質基準は `unresolved_questions.json` の人間ゲートで確定する。
