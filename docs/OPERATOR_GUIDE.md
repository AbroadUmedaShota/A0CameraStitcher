# 操作者向けの手順書（撮影と保存）

Issue #298。カメラを操作して撮影し、原画像を保存する人のための手順書です。開発者向けの仕様は [OPERATOR_UI_SPEC.md](OPERATOR_UI_SPEC.md)、決定の経緯は [DECISIONS.md](DECISIONS.md) にあります。この手順書では、操作に必要なことだけを書きます。

**どこを読むか:** 一台で撮る人は 2 章、二台で撮る人は 3 章（と 6 章の時間）。困ったときは 8 章（失敗したとき）と 9 章（USB を抜いたとき）。

## 0. まず知っておくこと

- この製品でできるのは、**カメラで撮って、撮った原画像をそのまま保存する**ところまでです
- **合成（2枚をつなげて1枚にする機能）は未対応です。** 画面に「合成」「再合成」と書かれたボタンや欄があっても、今は使えません。保存されるのは、カメラが撮った原画像そのものです
- 二台で撮るとき、撮影は **CAM-A、CAM-B の順に1回ずつ**行います。2台のシャッターが切れるタイミングは揃いません。ずれの大きさも保証していません
- 失敗しても、**自動ではやり直しません。** 撮った原画像も消しません
- 画面の文言は、できるだけ画面のとおりに「」で書いています。開発中の画面で、英語や技術用語が混ざった表示があります。意味は各章で説明します
- **アプリやカメラのプログラムを、タスクマネージャーなどで強制終了しないでください。** 一台でも二台でも、撮影中、機体照合の途中、終了を待っている間のどれでも同じです。閉じられないときは、技術担当者に連絡します
- **二台で撮るときは、技術担当者の立ち会いが前提です。** 今は、二台のアプリは技術担当者が起動します。操作者が自分で起動できるようにすることは決まっていて、#300 で変わる予定です（1章）。作業の前に、連絡先を決めておいてください。

### 用語

| 言葉 | 意味 |
| --- | --- |
| CAM-A、CAM-B | 2台のカメラの呼び名。本体の識別番号は書きません |
| 原画像 | カメラが撮った画像（JPEG）。加工しない、保存する元の画像です |
| 撮影ID | 1回の撮影につく番号。結果を確認するときの目印になります |
| カード | カメラに入れる記録カード。この製品では、画像をPCへ運ぶための一時置き場として使います |
| Camera Agent | カメラを動かす裏のプログラム。画面には「Camera Agent」と出ることがあります |
| 機体照合 | 2台のカメラのどちらが CAM-A で、どちらが CAM-B かを、人が目で見て決める作業 |
| ライブ表示（ライブビュー） | カメラが今見ている映像を画面に出す機能。構図やピントを見るためのもので、保存はされません |
| MF | ピントを手で合わせる設定（マニュアルフォーカス）。対義語は AF（オートフォーカス） |
| transaction | 撮影1回分の処理のまとまり。画面では「transaction」と英語のまま出ることがあります |
| SDK | カメラを制御するための部品（ソフトウェア） |
| spool | 画像を一時的に置くカード上の場所。「専用カードの spool」はカードが専用であることを指します |
| payload | カード上の画像などのデータ本体。「payload が0件」はカードが空という意味です |
| SHA-256 | 2つのファイルの中身が同じかを確かめる検査値。「一致」と出れば同じ内容です |
| ADR | 設計や運用の決定を記録した文書（DECISIONS.md にあります） |
| 採用 | 「採用して次の撮影を準備」の「採用」は、**撮った原画像を良しと記録して、次の撮影に進む操作**のことです。合成の採用とは関係ありません |

## 1. 撮影の前に

次を用意してから始めます。

1. 撮影に使う**専用のカード**を、カメラに入れる。**空**でなければなりません（画像だけでなく、動画やその他のファイルも0件）。空でないカードでは撮影できません。**カードの中身をPCから開かないでください**（エクスプローラーを使ったり、Windows のカメラ接続で開いたりしない）。空かどうかの確かめ方は、一台と二台で違います。
   - 一台: アプリの画面で確かめられます（2章の3）
   - 二台: 画面に、カードが空かどうかの表示はありません。空の確認は技術担当者が行います（3章の3）
2. 予備として、空のカードをもう1枚用意しておく
3. カメラとPCを USB でつなぐ。一台で撮るときは **CAM-A だけ**をつなぎます。もう一台がつながっていると撮影を断ります。つないだときに、Windows の「自動再生」や「フォト」の取り込みの案内が出ることがあります。**何も選ばずに閉じてください。** これらはカメラを別のやり方で読みに行くソフトなので、撮影とぶつかります
4. 二台で撮るときは、**CAM-A のレンズキャップを手元に用意する**（3章の機体照合で使います）
5. 撮影中は、カメラ本体のシャッターボタンを押さない。ほかのカメラ用ソフトも起動しない
6. 保存先として、このPC内のフォルダを決めておく（USB メモリ・SD カード・ネットワーク上のフォルダは選べません）

アプリの起動は、一台と二台で違います。

- **一台:** 起動したときの「起動モード選択」画面で、「SingleCameraを開始」を押します。押せないときは、画面に理由が出ます（例:「SDK非同梱のソフトウェア確認用候補。カメラ未照会」。意味は、カメラを制御する部品が入っていない版で、カメラにまだ問い合わせていない、ということ）。その場合は技術担当者に連絡してください
- **二台:** 今は、技術担当者が起動時の設定を付けて起動します。「起動モード選択」画面の「HardwareDual状態を表示」を押しても、起動方法の案内が出るだけです。操作者が自分で起動できるようにすることは決まっていて、#300 で実装する予定です。実装されるまでは、技術担当者が起動します

## 2. 一台で撮る（CAM-A）

画面の上に「HARDWARE / 実機1台」と出ます。「対象カメラ」で選べるのは CAM-A だけです。

1. 「保存先を選択」を押して、原画像を保存するフォルダを選ぶ。選ぶまでは「未選択（保存先を選択してください）」と表示され、撮影できません
2. 「安全確認」の**1項目め**にチェックを入れる。内容を読んで、事実のときだけ入れます。
   - 「物理シャッターと他のカメラアプリを使わず、Camera Agentを排他使用する」
3. 「状態を確認」を押す（1項目めのチェックだけで押せます）。「read-only状態確認」の欄に結果が出ます。
   - 「撮影準備OK」と出れば進めます。「撮影不可」のときは、その下の説明に理由が出ます。理由が分からなければ、技術担当者に連絡します
   - **カードが空かどうかは、この欄の説明の「spool payload: 0」で確かめます。** 0 なら空です。0 以外の数、または「未照会」のときは、4 の2項目にチェックを入れず、技術担当者に連絡します
   - カメラの設定は、確認して照らし合わせるだけです。**アプリはカメラの設定を書き換えません**
   - 「期限切れ」と出たら、一台用の撮影条件（プロファイル）の期限が過ぎています。撮影はできません。この表示が出るのは、状態を確認したあとに期限が来たときです。確認の時点で切れていれば「撮影不可」と出ます。技術担当者に連絡してください。「観測値を30日プロファイルとして承認」は、所有者か技術担当者だけが押します。**操作者は押しません**
4. 残りの2項目にチェックを入れる。これも、事実のときだけ入れます。
   - 「選択したD810の専用カードがsingle-slot spoolで、payload objectが0件である」（意味: カードが専用で、空である。3で「spool payload: 0」を見たときだけ入れる）
   - 「PC原画像の検証後、今回復元したexact objectだけを削除することを確認した」（意味: PCに保存した画像を確かめたあと、今回撮った1枚だけをカードから消す。カードの他の画像は消しません）
5. 構図を見たいときは、5章のライブ表示を使う
6. 「選択した1台を撮影」を押す。

   > **注意: 押すのは1回だけ。** 押したあと、画面が止まったように見えても、**結果の表示が出るまで待ってください。** 実績では、押してから成功の表示まで15〜19秒でした（目安で、仕様ではありません）。待っている間は、カメラのUSBを抜かない。シャッターボタンにも触らない。何度も押さない

   実績よりずっと長く表示が変わらないときは、押し直さずに、8章の「結果が分からないとき」へ進みます。
7. 結果を見る。成功すると「成功: CAM-A original.jpg」と出て、「一台撮影が完了しました。原画像を確認してから明示採用または保存してください。」と表示されます
8. 「単体原画像を保存」を押す。「保存」欄に「保存しました: 原画像1枚（CAM-A）。」と出て、「出力先」欄に保存したファイルの場所が出ます
9. 次の撮影に進むときは「採用して次の撮影を準備」を押す。採用しないときは「新しい撮影を準備」を使います。次の撮影も、2〜4の手順を最初から行います。採用のあとは、安全確認のチェックが**必ず外れます**。もう一度入れてください

### 一台でよく見る表示

| 表示 | 意味と対応 |
| --- | --- |
| 「再合成（SingleCameraでは対象外）」 | 押せません。合成は未対応です |
| 「Camera Agent実行ファイル: 未検出」 | 実機の操作を始められません。技術担当者に連絡する |
| 「期限切れ」 | 撮影条件の期限切れ。撮影不可。技術担当者に連絡する |
| 「未確定（新規撮影禁止）」 | 結果が分かっていません。8章へ |

## 3. 二台で撮る（CAM-A と CAM-B）

**技術担当者の立ち会いのもとで行います。** 二台では、画面に「撮影・回収のみ」のモードで、次の順に進みます。「撮影・回収のみ」は、撮って、原画像をPCへ受け取るところまで、という意味です。

### 3-1. 起動時の同意

1. 起動直後に「起動セッションの排他同意」が出る。2つにチェックを入れる。
   - 「撮影中に物理シャッターを操作しません」
   - 「他のカメラ撮影ソフトでカメラを占有しません」
2. 「同意して開始」を押す。同意するまで、撮影・保存を含むすべての操作ができません。同意はアプリを終了すると無効になります。「同意しない（操作を行わない）」を押したときは、機体照合も始めずに、アプリを閉じてください（※要検証: 押したあとの画面の動き）

### 3-2. カードとピントの用意

3. 2台のカードが**空**であることは、**技術担当者が確かめます。** 二台の画面には、カードが空かどうかを出す欄はありません（カメラの状態の欄は「実機状態は未判定（機体照合で確認）」のままです）。操作者は、**カードの中身をPCから開かないでください**（エクスプローラーや Windows のカメラ接続で開かない）。技術担当者から空と聞いていないカードは使いません
4. **2台とも、ピントを手動（MF）にする。** 次の2か所を確かめます（手順は [PILOT_CAPTURE_PROCEDURE.md](PILOT_CAPTURE_PROCEDURE.md) 6節）。
   - レンズに切り替えスイッチがあれば、M（マニュアル）にする
   - ボディのフォーカスモードセレクターを M にする

   実機の確認では、CAM-B がオートフォーカス（AF）のままで撮影が失敗しました（ピントが合わず撮れないエラー）。アプリはピントの設定を確認も変更もしません。撮影の前に人が確かめてください。2台とも MF にするのは、**現在の運用**です（ADR-0033 の6節。パイロット用の撮影についての決定）。製品の正式な運用にするかどうかは、まだ決まっていません（要決定）

### 3-3. 機体照合（どちらが CAM-A か決める）

カメラは2台とも同じ型なので、アプリは見分けられません。人が見て決めます。**取り違えても、アプリは気づけません。**

機体照合の画面は、起動時の同意（3-1）のあとに、**画面全体を覆って（中央に枠）自動的に出ます。** メニューの「機体照合を表示」は、この形では押せません（グレーです）。

> **時間に注意（6章）:** 「機体照合を開始」を最初に押した時点から、時計で時間を測り始めてください。**6分55秒より前に撮影を始めます。** 照合は手早く終え、6分55秒から逆算して、撮影の操作に必要な余裕を残します。同じ Camera Agent が動いている間は、押し直しても時間は戻りません。残り時間は通常の画面に出ません。

5. 「機体照合を開始」を押す。「候補を 2 台取得しました。1 台ずつ確認してください。」と出ます。2台でない場合は「接続台数が 2 台ではありません。2 台だけ接続してやり直してください。」と出ます
6. 「候補1」「候補2」のどちらかを選び、表示される映像を見て、どのカメラか判断する。見分け方は次のとおりです。実機の作業で使った方法で、**現在の運用**です。画面に案内はありません。製品の正式な運用にするかどうかは、まだ決まっていません（要決定）。
   - **CAM-A にレンズキャップを付けておく。** 映像が真っ暗な候補が CAM-A、映る候補が CAM-B
   - 照合画面の映像は、候補を選んだ瞬間の1枚で、その後は更新されません。**キャップは、2台の割当が終わるまで付けたまま**にします
7. 映像が出ている候補について「表示中を CAM-A にする」または「表示中を CAM-B にする」を押す。もう一台の候補も同じように割り当てる
8. 「両方の割当が終わりました。内容を確認してください。」と出たら、「この割当で確定します」の内容を読む。合っていれば「この割当で確定する」を押す
9. 「機体照合が完了しました。撮影を開始できます。」と出れば完了。ここからは **6分55秒より前に撮影を始めます**

**割当を間違えた・迷ったとき:** 照合の画面には、閉じるボタンも取り消しボタンもありません。「機体照合を開始」も、割当の途中と確認の画面では押せません。**「この割当で確定する」を押さずに、アプリを閉じ、技術担当者に連絡します。** 確定前なら、撮影もカードの操作も起きていません。

**確定したあとに取り違えに気づいたとき:** 画面に、やり直す入口はありません。**撮影せずに**アプリを閉じ、技術担当者に連絡します（※要検証: 実機では未確認）。

### 3-4. 撮影

10. **CAM-A のレンズキャップを外す。** ピントリングとシャッターボタンには触れません。外し忘れると、CAM-A は真っ黒な画像のまま成功と表示される見込みで（※要検証）、撮影1組分を使ってしまいます
11. 画面のチェック欄「専用カード2枚が空であることを確認し、合成・A0品質判定を行わない『撮影・回収のみ』を1回実行します。」にチェックを入れる。**技術担当者から、2枚とも空と聞いたときだけ**入れます。画面には、カードが空かどうかの表示はありません（3-2 の3）。
    - カードが空かどうかは、シャッターの直前に、アプリが各カメラで確かめます。空でなければ、そのカメラの撮影は止まり、撮影の失敗・部分失敗として出ます（画面での出方は ※要検証）
    - CAM-B のカードだけ空でないと、CAM-A だけ撮れて止まります（部分失敗、8章）
12. 主ボタン「2台を順次撮影・回収する（1回）」を押す。確認の画面は出ません。

    > **注意: 押すのは1回だけ。** 押したあと、画面が止まったように見えても、**結果の表示が出るまで待ってください。** 実績では、1組で23〜28秒でした（目安で、仕様ではありません）。画面に「この間は他の操作はできません。」と出ます。待っている間は、USBを抜かない。シャッターボタンにも触らない。何度も押さない

    実績よりずっと長く表示が変わらないときは、押し直さずに、8章の「結果が分からないとき」へ進みます。
13. 結果を見る。成功すると「原画像2枚の撮影・回収・再検証が完了しました。合成は実施せず、A0品質は未承認です。」と出ます（「A0品質は未承認」は、仕上がりの品質をまだ判定していない、という意味）

**時間切れで撮影が始まらないとき:** 撮影が始まらず、シャッターも切れていなければ、照合からやり直しです。**アプリを閉じ、技術担当者に連絡します**（6章）。

### 3-5. 保存と次の撮影

14. 保存先のフォルダを決める。「選択…」（またはメニュー「ファイル」の「原画像の保存先を選択(L)...」）で選びます。撮影の前に決めておいても、撮影後でもかまいません
15. 「原画像をこのPCのフォルダへ保存」を押す。

    > **注意: もう一度押すと、同じ画像が別の名前で追加保存されます。** 結果が出るまで待ってください。

    「保存しました: 2枚（CAM-A・CAM-B）。合成していない原画像です。保存先: …」と出れば完了です
16. 次の撮影は、**保存してから**「原画像を確認して次へ」か「撮り直しの準備へ」を押して、画面を戻してから始める。

    > **注意: 押すと、今の撮影の原画像は、この画面からは保存できなくなります。** 保存の完了を見てから押してください。メニュー「カメラ」の「readiness再検査」も同じです。保存の前に押さないでください。

    画面が戻ると、3-4 の11のチェックが外れます。次の撮影の前に、技術担当者から空と聞いたうえで入れ直します。機体照合は、同じ Camera Agent の間は続けて使えます。ただし6章の時間があります

画面に「最大5回」「最大5組」と出る場合は、受け入れ試験用の特別な起動です。担当者の指示に従ってください。

### 3-6. アプリを閉じる（二台）

撮影のあとにアプリを閉じると、「カメラの終了を待っています」と出ることがあります。Camera Agent が自然に終わるまで待って、もう一度閉じてください。0章のとおり、強制終了はしません（ADR-0032）。

## 4. 保存される原画像

- 原画像は、**PCで中身を確かめたあと**、アプリが決めた場所に保管されます。確かめられなかった画像は、保存済みとは扱いません
- あなたが「保存」を押すと、保管した原画像をそのまま（バイト単位で同一に）選んだフォルダへコピーします。画像の加工、上書き、自動削除はしません
- 保存の結果に「技術情報: 元の原画像と同一（SHA-256 一致）」と出れば、コピーが元と同じという確認ができています
- 保存に失敗したときは、画面の案内に従います。多くは次のどれかです。

| 画面の案内（要点） | 対応 |
| --- | --- |
| 保存先のフォルダが使えません | 「保存先を選択」（二台は「選択…」）で、このPC内の別のフォルダを選び直して、もう一度保存する。撮った原画像はアプリの中に残っています |
| 書き込みが最後まで完了しませんでした | 空き容量を確かめて、もう一度保存する。続けて失敗したら技術担当者に連絡する。撮った原画像はアプリの中に残っています |
| 「一部だけ保存できました」（二台） | 先に保存できた方のファイルは、そのまま使える。もう一度保存すると、2枚を別の名前でそろえて保存する。撮った原画像はアプリの中に残っています |
| アプリ内に保管した原画像を確認できませんでした | この撮影の原画像は、ここからは保存できません。保管場所のファイルを消さず、技術担当者に連絡する（この場合は、原画像がアプリの中に残っているとは言えません） |

## 5. ライブ表示（ライブビュー）

ライブ表示は、構図やピントを見るためのものです。画面の映像は原画像ではなく、保存もされません。

### 一台

1. 2章の1〜4（保存先、安全確認、状態確認）を終える。「撮影準備OK」になっていると使えます
2. 「継続Live Viewを開始」を押す。実績では、開始から4秒ほどで映像が動き出しました
3. 見終わったら「継続Live Viewを停止」を押す。「停止済み（SDK session closed）」（意味: カメラとの接続が閉じた）と出れば停止しています
4. 撮影ボタンを押すと、アプリが先に自動でライブ表示を止めてから撮影します。撮影が**成功したときだけ**、ライブ表示が再開します
5. 「停止未確認」と出たら、撮影は始まりません。「継続Live Viewを停止」をもう一度押して、停止を確認します

「採用して次の撮影を準備」のあとは、安全確認のチェックが必ず外れます。ライブ表示が動いている間はチェックを付け直せないため、先にライブ表示を停止します。

### 二台（今の形）

二台では、ライブ表示は**機体照合の画面だけ**です。候補を **1台ずつ**切り替えて見ます。メインの撮影画面には、実機のライブ表示はありません（「実機Live Viewは機体照合画面で確認」と出ます）。構図の確認やピントの確認は、この形では限られます。

### 二台（予定）

次のものは、まだ実装していません（#291）。

- 選んだ1台を動く映像で、反対側をその台の最後の静止画で出す
- 静止画の側に、画像を受け取った時刻を出す
- 「両方を更新」ボタンで、押したときだけ A、B の順に1枚ずつ取り直す
- 撮影できる残り時間（Camera Agent の起動から6分55秒まで）を画面に出す

最終的には2台とも動く映像にする方針ですが、時期は決まっていません。

## 6. 撮影できる時間（二台）

二台の撮影には、時間の制約があります。定義は [二台の撮影にかかわる時間の定義](HARDWARE_CAMERA_AGENT_DUAL_BINDING_V1.md#二台の撮影にかかわる時間の定義) にあります。

- Camera Agent は、起動から **10分**で自動的に終わります。延ばせません
- Camera Agent が起動するのは、最初に「機体照合を開始」を押した時です。同じ Camera Agent が動いている間は、押し直しても時間は戻りません。Camera Agent が終わったあとに押すと、新しい Camera Agent が起動し、時間は最初から数え直しになります。残り時間は通常の画面に出ません
- 撮影を始められるのは、Camera Agent の起動から **6分55秒以内**です。これを過ぎると、撮影の受付を断ります。このとき**シャッターは切れません**。6分55秒の**ぎりぎりで押すと断られることがある**ので、余裕を持って押してください
- 機体照合そのものには、期限がありません。ただし照合は Camera Agent の中にあるため、Camera Agent が終わると照合も消えます

**手順の側の目安:**

1. 最初に「機体照合を開始」を押したら、時計で時間を測り始める
2. 照合は手早く終える。6分55秒から逆算して、撮影の操作に必要な余裕を残す（何分で終えるかの決まった目安はありません。設計の文書で「5分」と書くと、撮影のボタンを押した時から数える別の5分を指すため、ここでは分数を書きません）
3. 6分55秒より前に、撮影のボタンを押す

迷っているうちに時間が過ぎると、照合のやり直しになります。実機では、映像から見分けられず迷って、時間切れになったことがありました。

**時間が切れたときの決まり:** 撮影が始まらず、シャッターも切れていなければ、**照合からやり直し**です。やり方は1つにします。**アプリを閉じ、技術担当者に連絡します。** 画面の「機体照合を開始」がまた押せるようになっていても、操作者は押しません（※要確認: 押して照合し直してよいか）。

画面の出方は2種類あります。

- 確定の前に10分が来たとき: 「機体確認用Agentの10分の利用期限が切れました。新しいAgentへ以前の割当は引き継がず、最初からやり直してください。」と出て、「機体照合を開始」が押せるようになります
- 6分55秒を過ぎたとき: 「撮影処理中に機体照合が無効になりました（理由: Agent の再起動）。撮影は再試行せず、2台の割当を最初からやり直してください。」と出る見込みです。シャッターは切れません（※要検証: 実機では未確認）

## 7. カードの扱い

- カードは、画像をPCへ運ぶための**一時置き場**です。残す場所はPCの原画像です
- アプリがカードから消すのは、**今回撮って、PCで中身を確かめた1枚だけ**です
- **カードの画像を一括で消す操作や、フォーマットは、しません。** アプリにもその機能はありません。手でやらないでください
- 撮影前にカードが空でなければ、撮影できません。空でない理由が分からないカードは、そのまま使わず、技術担当者に渡します
- 二台で、CAM-B のカードだけ空でないと、CAM-A だけ撮れて止まります（部分失敗）。撮り直すときは2台とも新しく撮ります（8章）
- 空でないカードを空にするのは、**所有者の判断があるときだけ**で、アプリと Camera Agent を終了してからです。操作者はしません。技術担当者が、画像をPCへ退避し、コピーが同じ内容か照合してから、1枚ずつ消します（手順は [PILOT_CAPTURE_PROCEDURE.md](PILOT_CAPTURE_PROCEDURE.md) 2節）
- 撮影が失敗した場合などに、カードに画像が1枚残ることがあります。アプリは、PCで確かめられなかった画像をカードから消しません。残った画像の扱いは技術担当者に任せます

## 8. 失敗したとき

### 基本の決まり

- **自動では再試行しません。** 同じ撮影IDを再開することもありません
- **原画像は消しません。** 失敗した撮影でも、PCに受け取れた原画像は保管されます
- 失敗のあとに撮るときは、**新しい撮影**として最初から行います。前回の片側の画像は再利用しません。二台で CAM-A だけ撮れた場合も、CAM-A と CAM-B の両方を撮り直します
- 結果が分からないときは、**撮り直さずに、まず結果を確認**します

### 画面の表示と対応

| 表示 | 意味 | 対応 |
| --- | --- | --- |
| 「transactionは失敗または部分失敗で確定しました。自動再試行しません。」（一台） | 撮影は失敗で終わった（transaction は撮影1回分の処理） | 原画像が保管されているか画面で確認し、「新しい撮影を準備」から新しく撮る |
| 撮影の結果が「撮影失敗（再開不可）」（一台） | 同上 | 同上 |
| 撮影の結果が「撮影失敗（再開不可）」（二台） | 撮影は失敗で終わった | 「撮り直しの準備へ」を押して、新しく撮る準備をする |
| 「途中で停止（原画像1枚を保管・詳細は技術情報）」（二台） | CAM-A の1枚だけ受け取れた（CAM-B を撮るのは、CAM-A が成功した後） | 保管した1枚を保存できる。撮り直すときは2台とも新しく撮る |
| 「1枚（CAM-A のみ。CAM-B の画像は受け取れませんでした）」 | 保存できたのは CAM-A の1枚だけ | 同上 |
| 「未確定（新規撮影禁止）」「未確定（再撮影禁止）」「結果が確定していません。」 | 結果が分からない | 下の「結果が分からないとき」へ |
| 「機体照合が無効になりました。撮影は開始していません。」 | 撮影の前に照合が消えた（6分55秒を過ぎた場合は、次の行の表示になる見込み。※要検証） | アプリを閉じ、技術担当者に連絡する（照合からやり直す。6章の「時間が切れたときの決まり」） |
| 「撮影処理中に機体照合が無効になりました（理由: …）。撮影は再試行せず、2台の割当を最初からやり直してください。」 | 撮影中にUSBの再接続などが起きた。6分55秒を過ぎた場合も、この表示になる見込み（※要検証） | アプリを閉じ、技術担当者に連絡する（照合を最初からやり直す） |
| 「接続台数が 2 台ではありません。2 台だけ接続してやり直してください。」 | カメラが1台しか見えない、または3台つながっている | 電源とUSBを確かめる。見えないカメラは、電源を入れ直すと見えたことがあった |

画面の「技術情報」には、技術担当者向けの詳しい情報があります。連絡するときは、撮影IDと画面の表示をそのまま伝えてください。

### 結果が分からないとき

結果が分からないのは、カメラの応答が途中で途切れたときなどです。

1. **新しい撮影を始めない。** カメラの電源を切ったり、USBを抜いたりもしない
2. 画面が止まったように見えるときは、まず結果の表示が出るのを待つ（実績: 一台 15〜19 秒、二台 23〜28 秒。目安で、仕様ではありません）。応答を待つ間は画面が操作をロックしていて、ボタンは押せません。ボタンが押せるようになったら、一台は「未確定transactionの結果を確認」、二台は「同じ撮影IDの結果を確認する（撮影しません）」を押す（アプリは最大4分ほど待ちます）。二台では、結果の画面から「撮り直しの準備へ」で撮影画面に戻ると、このボタンが出ます
3. 確認が終わると、結果が確定します。画像があれば保存できます
4. 確認しても分からない、または何度も出るときは、技術担当者に連絡する。待つ目安は3分です（※要確認: 上限は未定。根拠の候補は、二台の撮影1回分の処理を見張る上限が180秒であることと、撮影の応答を待つ上限が一台・二台とも240秒であること。※要検証）。アプリを閉じて開き直した場合も、未完了の撮影があれば、結果の確認しかできません

**撮影前の確認:** 技術担当者が、**アプリを起動する前と、結果不明が1回でも出た後の、次の撮影の前**に行います（確認する項目は [PILOT_CAPTURE_PROCEDURE.md](PILOT_CAPTURE_PROCEDURE.md) 2節の1〜3、ファイルの3点）。

### ピントが合わず失敗したとき

二台で、CAM-B の撮影だけが失敗し、CAM-A の1枚だけ保管されたことがありました。原因は、CAM-B がオートフォーカスのままだったことが疑われています（※要確認）。3章の4で、2台とも M になっているかを確かめてから、新しく撮り直します。

## 9. USB を抜いたとき

**撮影中に、USB を抜かないでください。** 一台の画面には「物理シャッター・他のカメラアプリを使わず、撮影中にUSBを抜かないでください。自動再試行は0回です。」と出ています。この注意文は二台の画面には出ませんが、二台でも同じです。

実機での確認結果は次のとおりです。

- 撮影ボタンを押したあとに一台の USB を抜くと、**十数秒で、撮影が失敗として止まりました。** 成功とは表示されません。自動では再試行しません
- 二台で CAM-B の USB を抜くと、CAM-A の撮影と保管は終わっていて、CAM-B は失敗で止まりました。CAM-A の原画像は保管されたままです
- アプリは、抜けたカメラのカードの画像を消しません。**カードに撮影済みの1枚が残ることがあります。** その1枚を、操作者は消さないでください

抜けたときの対応です。

1. 画面の表示を読む。何も押さずに待ち、終わりの表示を確かめる
2. USB は技術担当者の指示でつなぎ直す。**つなぎ直すと、二台の機体照合は消える**ので、3章をやり直す
3. カードに画像が残っているかは、技術担当者が確かめて、PCへ退避してから消す
4. 撮り直すのは、そのあとに、新しい撮影として行う

ライブ表示の最中や、機体照合の最中に抜いたときの動きは、まだ記録がありません（※要確認）。
