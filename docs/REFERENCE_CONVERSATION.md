## ユーザーが明示した条件

- Nikon D750を2台使用する。
- 対象は静止物または遠景であり、動体は対象外とする。
- カメラは固定設置し、手持ち運用は対象外とする。
- 左右画像に十分な重複を確保する。
- Windows専用アプリでよい。
- 撮影から完成まで1〜10秒程度を許容する。
- ハードウェア同期装置は追加しない。
- USB接続のみで操作する。
- ミリ秒以下の実シャッター同期保証は要求しない。
- 視差の大きい近距離立体物、完全リアルタイムRAW合成は対象外とする。

## 再設計で採用候補になった内容

- WPD/PTPを使ったカメラ単位の制御をPhase 0で検証する。
- 撮影命令は2台へ並列に発行し、画像転送は初期版では直列化する。
- シリアル番号等の永続識別子で左右を固定する。
- 左右画像を `CaptureTransactionId` で対応付ける。
- 固定リグのキャリブレーション結果を再利用する。
- 原画像を必ず保存し、合成失敗時も破棄しない。
- JPEG Fineから開始し、NEF/RAWは後続とする。
- Nikon Camera Remote SDKは二台同時制御に採用しない。

## 会話から変更した点

- 本プロジェクトの第一対象は、棚卸し表の記載に合わせて「A1より大きい平面原稿を撮影するA0対応ツール」とする。遠景パノラマはMVP対象外とする。
- .NETの採用版は、2026-08-03時点でActive LTSの.NET 10を候補とする。
- WPD/PTPでD750が実際に二台撮影できることは確定事項ではなく、Phase 0の検証対象とする。
- 出力解像度、DPI、リグ寸法、レンズは未確定の人間判断事項として残す。

## 公式確認済み事項

- Nikon公式FAQはCamera Remote SDKによる複数カメラ同時制御を非対応としている。
- Nikon公式SDK配布一覧にはD750用SDKが掲載されている。
- D750の最大記録画素数は6016×4016ピクセル（L）。
- Microsoft WPDには静止画撮影開始コマンドとObjectAddedイベントモデルがあるが、D750ドライバが必要機能を公開するかは実機確認が必要。
- .NET 10はActive LTSで、サポート終了は2028-11-14の予定。
